# README

This chapter defines interfaces, schemas, contract mappings, deployment configuration, metering and billing, compatibility and economic mechanisms. All kinds of parameters are injected through the signed registry and versioned policy; the loader automatically validates source, type, range and dependencies, and business execution records authorization, cost, service, proof and settlement statuses together.

{% hint style="info" %}
**Technical contract**: REST, SDK, MCP and backend adapters share object, authorization, idempotency and receipt semantics. Addresses, assets, prices and service levels are provided by the deployment registry, asset description files and price tables, and signature verification and consistency validation are completed at runtime.
{% endhint %}
