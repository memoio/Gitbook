# README

MEMO Protocol, MEFS, Data Wallet, Data Market, DataDrive, MEMO DID, Smart Layer, Storage Middleware, Meeda, FileProof, Attestation, compute platform, x402 and node economics correspond respectively to the capabilities of protocol, storage, identity, verification, computation, applications and settlement. In the Agent State Layer architecture, they take on the responsibilities of state storage, identity control, evidence verification, controlled processing and settlement through versioned adapters, and collaborate under unified object references, delegation and receipt rules.

{% hint style="info" %}
**Product positioning: the protocol network, encrypted storage, identity control, proof services and application entry points make up composable infrastructure.** Vault unifies state objects and the Local / Hosted / MEFS backends; Gateway enforces managed access and delegation policy; Proof organizes evidence, aggregation and anchoring. The service registry pins each component's interface version, network domain, endpoint, key enforcement location and verification configuration, and adapters automatically check the matching relationships at load time and on every call.
{% endhint %}
