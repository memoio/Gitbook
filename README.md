# README

The MEMO Agent State Layer is trusted state infrastructure for agents. It uses MEMO Protocol as the common foundation and organizes the storage, identity, proof and delivery responsibilities of MEFS, Meeda, MEMO DID, FileProof, Data Wallet and Data Market into a unified state service. Vault manages state objects and storage, Agent Gateway enforces identity, delegation and access policy, and Proof organizes provenance, runtime and storage evidence.

{% hint style="info" %}
**Product positioning:** state infrastructure that is independent of models and agent frameworks, providing consistent mechanisms for state ownership, controlled access, version continuity and evidence verification. Service discovery, interface versions and deployment configuration are managed through a signed registry and compatibility descriptors; for the shared definitions, see [Core Technical Principles](file:///5907924/preface/core-principles.md).
{% endhint %}
