# 1 开始了解 MEMO

MEMO Agent State Layer 是面向 Agent 的可信状态基础设施，以 MEMO Protocol 为共同底座，将 MEFS、Meeda、MEMO DID、FileProof、Data Wallet、Data Market 的存储、身份、证明与交付职责组织为统一的状态服务。Vault 管理状态对象与存储，Agent Gateway 执行身份、委托和访问策略，Proof 组织来源、运行与存储证据。

{% hint style="info" %}
**产品定位**：独立于模型和 Agent 框架的状态基础设施，围绕状态归属、受控访问、版本接续与证据核验提供一致机制。服务发现、接口版本和部署配置通过签名注册表及兼容性描述文件管理；共同定义见[核心技术原则](/broken/pages/48dedc4efea4d5dcdfbd7ade144a232a56a50b93)。
{% endhint %}
