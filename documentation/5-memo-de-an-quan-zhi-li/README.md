# 5 MEMO 的安全治理

MEMO 的安全治理覆盖用户身份、文件归属、按约保存验证与 Agent 状态控制。Agent 场景需要区分“谁拥有数据”“哪个 Agent 与实例正在行动”“权限由谁授予”，并对记忆来源、运行内容、工具结果和外部副作用保留有范围的证据。身份、授权、数据保护和审计共同构成安全控制体系；策略引擎、密钥执行点与证据验证器分别执行准入、密钥释放和证据核验，控制结果写入版本化回执。

{% hint style="info" %}
**产品定位：面向 Agent 状态全生命周期的身份、授权与风险控制体系。** Owner 预先签署委托范围和策略配置，Gateway 在每次受管请求及实际交付前自动校验；来源准入、风险处理、验收与故障恢复使用可执行规则，并以独立业务状态和证据状态记录结果。
{% endhint %}
