# 9 能力配置、支持与社区

MEMO Agent State Layer 采用三种可组合的能力配置：**基础配置提供可控记忆，协作配置提供可携状态与证明，生态配置提供接口适配与选择性交付**。配置关系表达模块依赖和服务范围；部署系统依据签名清单装配组件、加载策略并执行自动验证。

| 配置域           | 职责与组成                                    | 配置及自动验证机制                             |
| ------------- | ---------------------------------------- | ------------------------------------- |
| 协议与基础组件       | Protocol、存储、身份、验证和执行能力                   | 注册表绑定组件版本、协议参数、网络与服务端点                |
| 基础配置：可控记忆     | Vault、候选准入、来源、版本、导入导出与本地回执               | 检查对象 Schema、密钥、准入策略、恢复与权限拒绝路径         |
| 协作配置：可携状态与证明  | 身份连续性、Checkpoint、Handoff、Trace、回执与 Proof | 检查依赖、接收者授权、封装映射、证据链与故障恢复              |
| 生态配置：适配与选择性交付 | 框架和协议适配、企业连接器、资产用途许可与结算                  | 匹配 Compatibility Profile，校验权利、预算和交付策略 |
| 维护与服务配置       | 版本记录、入口发现、诊断、支持与安全响应                     | 签名分发、健康探测、脱敏诊断、事件分级和回退                |
