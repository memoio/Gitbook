# 附录 C：图表绘制提示词

本附录汇总全部 32 张图的绘图提示词。每份提示词包含“绘图风格”和“绘图内容”两部分，可单独复制到绘图工具中使用；风格要求与[A.7 图表风格与绘图提示词规范](/broken/pages/e75e42d7aa6b9ed58e86efcc2972186e1f7a6dff#a-7)一致，节点、方向与条件以对应图的图源为准。

<summary>图 01｜MEMO Agent State Layer 产品与基础设施关系</summary>

对应图：[图 01](/broken/pages/98166d8152e35b91f91d518508340027a071cc02#figure-01)（整体产品关系）

```
绘图风格：
绘制一张 16:9 横版科研论文式图。仅使用纯白背景、黑色文字、黑色轮廓与黑色连线；禁止彩色、灰色填充、渐变、阴影、3D 和装饰性插画。采用规则矩形、统一线宽、规则网格和充足留白，所有节点内部保持纯白。通过实线、虚线、编号与文字标签区分关系，不使用颜色或线宽差异编码。中文清晰可读，同层级字号统一，英文产品名、协议名和字段名拼写准确；避免文字与连线重叠。每行最多排列5个主要节点，复杂流程按具体内容分层或分区，适应横版画布。输出黑白 4K PNG（3840 × 2160）或可编辑 SVG，保证缩小与黑白打印后仍清晰。

绘图内容：
采用上下分区的体系架构布局，每层最多四个主要矩形，跨区连线从外侧走线。顶部设置“用户 / 组织”“Data Wallet：用户控制入口”和“Agent / 应用 / 框架”；用户指向 Data Wallet，Data Wallet 与 Agent / 应用 / 框架分别指向“MEMO Agent Gateway：身份、委托、策略、回执”。Gateway 指向“MEMO Vault：状态对象、版本、加密、生命周期”；Vault 分别指向“Local / Hosted”及“MEFS：长期存储、冗余、修复、存储证明”。将“MEMO Proof：来源、运行证据、审计根、存储证明”置于下部，Gateway、Vault、MEFS 各自以独立箭头汇入 Proof；Proof 再指向“链上承诺 / 验证合约 / 挑战与裁决”。
侧边保留“MEMO Protocol”，用三条无箭头实线分别连接 Gateway、Vault、Proof，表示底座关系。把“Meeda / FileProof / Attestation”以实线箭头接入 Proof；“算力平台 / TEE / x402 / Data Market”用标注“可选扩展”的虚线箭头接入 Gateway。图例区分有向关系、无箭头底座关系和由部署配置选择的扩展。Local / Hosted 保持为一个节点，不增画其到 Proof 的连线。链上区域只接收图示证据与登记，不画状态原文或密钥流入链上；各组件通过版本化接口与注册表连接。
```
